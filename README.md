# CreatorPilot AI 🚀

An AI-powered full-stack web application designed to help content creators streamline their workflow, manage audience engagement, organize content calendars, and generate AI-driven insights and thumbnails.

## 🛠️ Tech Stack

* **Frontend:** React, Vite, Tailwind CSS / Modern CSS
* **Backend:** Python 3.14, FastAPI, Uvicorn, Pydantic
* **Database:** MongoDB (`pymongo`)
